# Test Plan - Online Gadget Store

## 1. Project Overview

Project Name: Online Gadget Store

Project Description:  
Online Gadget Store is an e-commerce website where users can view products, create accounts, add products to the shopping cart, place orders, and leave reviews.

Testing Objective:  
The main goal of testing is to check that the website works correctly, provides a good user experience, and meets the requirements.



## 2. Testing Scope

### Features Included in Testing

The following features will be tested:

- User registration
- User login and logout
- Product search
- Product details page
- Product reviews
- Adding products to the shopping cart
- Removing products from the shopping cart
- Updating product quantity
- Checkout process
- Order confirmation
- Website navigation
- User interface elements

### Features Not Included in Testing

The following areas will not be tested:

- Server performance testing
- Advanced security testing
- Database testing
- External payment systems



## 3. Testing Types

### Functional Testing

Checking that all website features work according to the requirements.

### UI Testing

Checking that all visual elements are displayed correctly.

### Usability Testing

Checking that the website is easy and comfortable to use.

### Regression Testing

Checking that new changes do not affect existing features.

### Compatibility Testing

Checking that the website works correctly on different browsers and devices.



## 4. Test Environment

### Hardware:
- Laptop/Desktop computer
- Mobile device

### Operating Systems:
- Windows
- macOS
- Android/iOS

### Browsers:
- Google Chrome
- Mozilla Firefox
- Safari



## 5. Testing Tools

The following tools will be used during testing:

- Google Sheets / Excel - for managing test cases
- Jira - for reporting and tracking bugs
- Browser DevTools - for checking website elements
- GitHub - for storing testing documentation



## 6. Test Approach

Testing will be performed manually.

Testing process:

1. Analyze requirements
2. Create test scenarios
3. Create test cases
4. Execute test cases
5. Report found bugs
6. Verify bug fixes
7. Perform regression testing



## 7. Entry Criteria

Testing can start when:

- The website is available for testing
- Main features are implemented
- Test environment is ready
- Requirements are available



## 8. Exit Criteria

Testing can be completed when:

- All planned test cases are executed
- Critical bugs are fixed
- Test results are documented
- Final test report is prepared



## 9. Bug Management

All found bugs will include:

- Bug ID
- Bug title
- Bug description
- Steps to reproduce
- Expected result
- Actual result
- Severity
- Priority



## 10. Risks

Possible risks:

- Requirements may change during testing
- Some features may not be ready for testing
- Test environment problems may affect testing



## 11. Test Deliverables

The following documents will be created:

- Test Plan
- Test Scenarios
- Test Cases
- Checklist
- Bug Reports
- Test Execution Report
