# Test Scenarios 

## Project: Online GadgetGO Store

## Purpose

The purpose of this document is to describe the main test scenarios that will be checked during website testing.


## User Account

- TS_001 : Verify that a user can create a new account
- TS_002 : Verify that a user can login with valid credentials 
- TS_003 : Verify that a user cannot login with invalid credentials 
- TS_004 : Verify that a user can logout from the account 
- TS_005 : Verify that a user can reset the password 


## Product Search and Navigation

- TS_006 : Verify that a user can search for products 
- TS_007 : Verify that search results are displayed correctly 
- TS_008 : Verify that a user can open product details page 
- TS_009 : Verify that product information is displayed correctly 
- TS_010 : Verify that website navigation links work correctly 


## Shopping Cart

- TS_011 : Verify that a user can add a product to the shopping cart 
- TS_012 : Verify that added products are displayed in the cart 
- TS_013 : Verify that a user can remove a product from the cart 
- TS_014 : Verify that a user can update product quantity 
- TS_015 : Verify that the total price is calculated correctly 


## Checkout Process

- TS_016 : Verify that a user can start the checkout process 
- TS_017 : Verify that checkout fields are validated 
- TS_018 : Verify that a user can complete an order 
- TS_019 : Verify that order confirmation is displayed 


## Product Reviews

- TS_020 : Verify that a user can view product reviews 
- TS_021 : Verify that a user can submit a review 
- TS_022 : Verify that reviews are displayed correctly 


## User Interface

- TS_023 : Verify that website elements are displayed correctly 
- TS_024 : Verify that buttons work correctly 
- TS_025 : Verify that images are displayed correctly 


## Compatibility Testing

- TS_026 : Verify that the website works correctly in Google Chrome 
- TS_027 : Verify that the website works correctly in Mozilla Firefox 
- TS_028 : Verify that the website works correctly on mobile devices
