# Bug Report 

Bug 1:User Cannot Edit Website Review

Bug ID: BUG_REVIEW_001

Related Test Case: TC_REVIEW_003

Title: Website review cannot be edited after submission

Environment:
- Website: Online Gadget Store
- Browser: Google Chrome

Preconditions:
User has already submitted a website review.

Steps to reproduce:
1. Open the website reviews section.
2. Select an existing review.
3. Click the Edit button.
4. Try to save changes.

Expected Result:
The user should be able to edit and save changes to the submitted review.

Actual Result:
The review cannot be edited after submission.

Severity: Low

Priority: Medium

Status: Open
