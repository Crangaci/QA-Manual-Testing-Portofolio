# Bug Reports

## Bug 1: Search function does not return results

Bug ID: BUG_SEARCH_001

Related Test Case: TC_PRODUCT_001

Title: Search button does not display search results

Environment:
- Website: Online Gadget Store
- Browser: Google Chrome

Preconditions:
User is on the website.

Steps to reproduce:
1. Open the website.
2. Enter a product name in the search field.
3. Click the Search button.

Expected Result:
Products related to the search query should be displayed.

Actual Result:
No results are displayed and the search function does not work.

Severity: Medium

Priority: High

Status: Open
