# Product Catalog Test Cases

## Test Case 1: Display product categories

Test ID: TC_PRODUCT_001

### Scenario: User can view available product categories.

Steps:
1. Open the Shop page.
2. Check the available product categories.
3. Select categories such as Smartphones, Tablets, Accessories, Computers.

Result:
All product categories are displayed correctly.

Status: Pass

## Test Case 2: Display products by category

Test ID: TC_PRODUCT_002

### Scenario: User can see products belonging to the selected category.

Steps:
1. Open the Shop page.
2. Select a product category.
3. Check the displayed products.

Result:
Only products related to the selected category are displayed.

Status: Pass
