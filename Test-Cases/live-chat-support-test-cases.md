# Live Chat Support Test Cases

## Test Case 1: Open live chat

Test ID: TC_CHAT_001

### Scenario: User can open the live chat window.

Steps:
1. Open the website.
2. Click the live chat button.

Result:
The live chat window is opened successfully.

Status: Pass


## Test Case 2: Send message through live chat

Test ID: TC_CHAT_002

### Scenario: User can send a message through live chat.

Steps:
1. Open the live chat window.
2. Enter a message.
3. Click the Send button.

Result:
The message is sent successfully and is visible in the chat.

Status: Pass
