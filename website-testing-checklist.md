# Website Testing Checklist 

## Purpose

This checklist is used to quickly verify the main website features before or after testing.


## User Account

- [ ] User can create a new account
- [ ] Registration with empty required fields shows validation messages
- [ ] Registration with an existing email is not allowed
- [ ] User can log in with valid credentials
- [ ] User cannot log in with invalid credentials
- [ ] User can log out successfully
- [ ] User can reset the password


## Product Search

- [ ] Search bar is displayed correctly
- [ ] User can search for existing products
- [ ] Search results are displayed correctly
- [ ] No results message is displayed for unavailable products


## Product Details

- [ ] Product name is displayed correctly
- [ ] Product price is displayed correctly
- [ ] Product description is displayed correctly
- [ ] Product image is displayed correctly


## Shopping Cart

- [ ] User can add a product to the cart
- [ ] Added products are displayed in the cart
- [ ] User can update product quantity
- [ ] User can remove a product from the cart
- [ ] Total price is calculated correctly
- [ ] Empty cart message is displayed when the cart has no products


## Checkout

- [ ] Checkout page opens correctly
- [ ] Required fields are validated
- [ ] User can complete an order
- [ ] Order confirmation message is displayed


## Product Reviews

- [ ] Product reviews are displayed correctly
- [ ] User can submit a review
- [ ] Validation message is displayed for an empty review


## User Interface

- [ ] Buttons work correctly
- [ ] Links work correctly
- [ ] Images are displayed correctly
- [ ] Website layout is displayed correctly
- [ ] Navigation menu works correctly


## Compatibility

- [ ] Website works correctly in Google Chrome
- [ ] Website works correctly in Mozilla Firefox
- [ ] Website works correctly on mobile devices


## Final Check

- [ ] No critical issues found
- [ ] All important features were tested
- [ ] Testing documentation is complete
